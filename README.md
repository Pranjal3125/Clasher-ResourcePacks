## Use

1. Download the ZIP archive from the repository.
2. Keep the archive intact unless you intend to edit the pack.
3. Import it into Minecraft Bedrock using the platform's resource-pack import flow.
4. Enable it in the appropriate world or server resource-pack settings.

Compatibility can depend on the Minecraft version and pack manifest. Check the pack's metadata in-game if it fails to import or displays missing textures.
