## How to Use

1. Download the `.zip` archive from this repository.
2. Keep the archive intact unless you intend to customize the pack.
3. Import it into Minecraft Bedrock using the platform's resource-pack import flow.
4. Enable it in your world or server resource-pack settings.

> Compatibility depends on the Minecraft Bedrock version and pack manifest. If textures appear missing or import fails, check the pack manifest in-game or open an issue with your Minecraft version and logs.
